# Claudex brand assets

Drop the Claudex logo here as `logo.png` (the violet 6-petal flower with the orange asterisk burst, on a near-white background).

The README hero image is loaded from `assets/logo.png` — once you save the file at that path it will render automatically on GitHub.

Recommended:
- `logo.png` — full lockup, 1664×936 (the file you have)
- `logo-square.png` — square variant for npm / social cards
- `logo-mark.png` — just the flower mark, no wordmark, for favicons
